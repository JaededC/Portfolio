# Jim Castellvi — Portfolio

A personal portfolio built with HTML and CSS for my Web Technology class.

What began as a straightforward class assignment gradually became an opportunity to experiment with web design, learn new CSS techniques, and build a space to showcase my projects and professional journey.

## The Basic CSS Assignment

This project was originally a simple HTML website that needed some CSS styling: a navigation bar, hover effects, a consistent color theme, and a footer.

Then I started looking for design inspiration.

I came across a portfolio that caught my attention and decided to challenge myself to recreate some of its visual effects. What followed was roughly three days of experimenting, breaking things, fixing them, and repeatedly asking myself, *"Wait, can I do that?"*

A navbar turned into glassmorphism. A few hover effects turned into experiments with 3D transforms. Choosing a color turned into exploring gradients, shadows, CSS variables, and entire color palettes.

Before I knew it, I had redesigned most of my portfolio.

### What I Learned Along the Way

- **HTML structure:** Better understanding of nesting, parent-child relationships, semantic elements, and how HTML structure affects styling.
- **Flexbox and CSS Grid:** Building navigation, hero sections, and project layouts while learning how elements behave in different containers.
- **CSS variables:** Discovering `:root` and `var()` completely changed how I experimented with colors, gradients, and reusable styling.
- **Reusable classes:** Realizing an element could have multiple classes was a surprisingly big revelation. It made me rethink how to organize shared effects.
- **Animations and interactions:** Experimenting with transitions, transforms, perspective, hover effects, and deciding when an effect actually improved the design.
- **Debugging layouts:** Learning that a misplaced container, an incorrect selector, or a poorly chosen width could affect an entire page.
- **Design consistency:** Finding a balance between soft backgrounds, sharper gradients, subtle shadows, and visual hierarchy.

### A Few Lessons Beyond CSS

One of my biggest takeaways was that **just because I could implement something didn't mean it belonged in the design.**

I experimented with effects that looked interesting individually but didn't necessarily fit the rest of the website. I also went through several color palettes before settling on something that felt right.

I learned the value of reusable styles a little late. There are still redundant declarations, hardcoded values, and beginner mistakes throughout the CSS. Rather than pretend otherwise, I've kept much of that original learning process visible.

The project also reminded me how much I enjoy learning through experimentation. I often started with a visual idea before knowing how to implement it, then worked backward to learn the necessary techniques.

**My design ideas were frequently ahead of my technical knowledge, and figuring out how to close that gap was half the fun.**

### What's Next?

The website is still evolving. My next steps include cleaning up the stylesheet, improving responsiveness and accessibility, refining project case studies, and eventually implementing a functional contact form.

For now, this repository represents both a personal portfolio and a snapshot of my early experience learning frontend development.

## Running Locally

No build step or dependencies are required.

1. Download or clone this repository.
2. Keep the HTML files, CSS file, and `webtech_img` folder in their original structure.
3. Open `index.html` in a browser.

**Note:** `About.html` uses a capital `A`, so preserve the filename when linking between pages.
